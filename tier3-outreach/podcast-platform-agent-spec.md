# Podcast Platform Agent Spec — Tier 3 Outreach & Visibility
**Agent ID:** T3-06  
**Version:** v1.0  
**Status:** 🟢 ACTIVE

## Mandate
Maintains RSS metadata, tags, and multi-platform podcast discoverability.

## Owned Artifacts
- RSS feed XML
- Episode metadata (EP-12)
- Show notes with canonical URLs

## Platforms
- Spotify
- Apple Podcasts
- YouTube (audio + waveform)
- LinkedIn audio embeds

## Key Responsibilities
1. RSS feed maintenance and validation
2. Tag optimization for discoverability
3. Multi-platform syndication scheduling
4. Sync with Podcast Agent (T1-03) for content updates

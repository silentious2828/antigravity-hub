## Governance

Enterprise agents follow the operational modes defined in `ARCHITECTURE.md`:
- **Autonomous Mode:** No human required (lead scoring, invoicing, monitoring)
- **Human-in-the-Loop Mode:** Fast approval required (proposals, outreach copy)
- **Strategic Mode:** Weekly review (forecasting, competitor brief, pipeline health)

# Risk Mitigation Agent Spec — Tier 2 Metrics & Analytics
**Agent ID:** T2-03  
**Version:** v2.3  
**Status:** 🟢 ACTIVE

## Mandate
Monitors system risk signals and triggers contingency protocols.

## Risk Thresholds
- Posting gaps > 2 weeks
- Low engagement < 3%
- Shallow network (Inner layer < 5 connections)
- ATS match rate drop below 85%
- Application conversion below 15%

## Key Responsibilities
1. Real-time risk signal monitoring
2. Contingency mapping
3. Escalation to Governance Agent (T4-01) on critical thresholds
4. Monthly risk matrix report to Risk Matrix Agent (T5-09)

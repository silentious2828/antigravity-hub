# 🛸 route-optimization-v1

Omiroute routing pipeline project.

## Structure
- `notebooks/` — Jupyter notebooks and execution scripts
- `data/` — Datasets and routing inputs
- `config/` — Routing configurations and YAML specs

## Quick Start
1. Copy `.env.example` to `.env` and fill in your keys
2. Install dependencies: `pip install -r requirements.txt`
3. Launch the notebook: `jupyter notebook notebooks/mission-control.ipynb`
